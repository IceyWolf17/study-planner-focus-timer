# Study Planner Focus Timer

A mobile-first Pomodoro study planner built with React, Tailwind CSS, and Radix UI.

## Features

- **Focus Timer** — Pomodoro-style timer with customizable focus and break durations
- **Task Management** — Add, complete, and delete study tasks with a quick-view in the timer tab
- **Statistics Dashboard** — Track completed sessions, total focus time, and tasks finished
- **Mobile-first UI** — Designed at 1080×1920 with bottom tab navigation and large touch targets

## Tech Stack

- React 18
- Tailwind CSS v4
- Radix UI primitives
- Lucide React icons
- Sonner toasts
- Vite

## Getting Started

```bash
npm install
npm run build
```
